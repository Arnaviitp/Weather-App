# Weather App ⛅️

A responsive web application that fetches and displays weather forecasts for user-specified cities, leveraging modern front-end frameworks and real-time weather APIs.

---

## 🚀 Features

- Search for city-specific weather by name  
- Display current weather and forecast (e.g. hourly or 7-day summary)  
- Toggle between Celsius and Fahrenheit  
- Responsive layout for mobile and desktop  
- Option to show weather-related icons or animations

---

## 🧪 Tech Stack

| Component         | Tools / Technologies           |
|------------------|-------------------------------|
| Frontend          | React.js / Next.js            |
| Styling           | Tailwind CSS / CSS Modules     |
| API               | OpenWeatherMap / Weather API  |
| Deployment        | Vercel / Netlify              |
